# Contributing

Thanks for your interest in contributing.

## Scope
This repository contains the planning docs and early build scaffold for a personalized AI operator product. Contributions should stay aligned with the product direction described in the docs already in the repo.

## Ways to contribute
- Improve documentation
- Suggest or implement MVP features
- Add frontend or backend scaffolding
- Improve developer setup
- Add tests
- Fix bugs
- Suggest architecture improvements

## How to contribute
1. Fork the repository or create a branch from `main`.
2. Make small, focused changes.
3. Use clear commit messages.
4. Open a pull request with a short explanation of:
   - what changed
   - why it changed
   - anything reviewers should test

## Branch naming
Use one of these patterns:
- `feature/short-description`
- `fix/short-description`
- `docs/short-description`
- `chore/short-description`

## Pull request checklist
- The change is focused and understandable.
- Documentation was updated if needed.
- No secrets or credentials were added.
- New environment variables were documented in `.env.example`.

## Coding expectations
- Keep files simple and readable.
- Prefer small, testable changes.
- Match the existing naming and folder structure.
- Avoid unnecessary dependencies.

## Discussions first
For large changes, open an issue first before building so the direction can be agreed early.
