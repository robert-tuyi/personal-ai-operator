# Personal AI Operator

AI operator that learns a user's work style and helps handle email, scheduling, follow-ups, meeting notes, and task orchestration with approval controls.

## Vision
Build a personalized cognitive twin for knowledge workers that can observe, recommend, draft, and gradually automate routine work.

## Problem
Knowledge workers lose time to repetitive communication, scheduling, status tracking, and context switching.

## Solution
A personal AI operator that:
- Learns writing style and preferences
- Connects to email, calendar, docs, and tasks
- Drafts replies and follow-ups
- Turns meetings into decisions and action items
- Operates with approval rules and audit logs

## Initial target user
Busy founders, executives, consultants, and project managers who handle large volumes of communication and coordination.

## MVP
- Email and calendar integration
- Personal memory layer
- Draft replies in user style
- Meeting summaries and action extraction
- Daily brief
- Approval-based task execution
